# Node_Rest_APIs_Typescript-

This is very basic rest APIs using NODe express with typescript.

## Here i separate our js and ts file 

--> Our generate javascript files in dist folder with the help of outDir in tsconfile.json file
--> Our source typescript file in src folder with the help of rootDir in tsconfile.json file

# Note:

--> Node is not capable to run typescript code.
--> It is capable of running Javascript files, Therefore we need to compile ts file into js file wit the help of typescript compiler (tsc).

# How to Test This Basic APIs.
--> STEP 1: first clone this repo and 
--> STEP 2: cd dist (run in terminal)
--> STEP 3: node app.js (run in terminal)
